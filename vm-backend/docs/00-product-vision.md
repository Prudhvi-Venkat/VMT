# Product Vision

## Scope

Applications, APIs, servers, endpoints, containers, Kubernetes, cloud,
databases, network, repositories, IaC, SBOMs, SaaS and third-party
software.

## Core lifecycle

`Source → Ingestion → Normalization → Correlation → Finding/Evidence → Risk → Owner → Workflow → Remediation → Verification → Historical Intelligence`

## Principles

-   Canonical security model
-   Provenance preservation
-   Hierarchical tenancy
-   Policy-driven behavior
-   Event-driven scale
-   Explainable risk
-   Historical intelligence
-   Controlled automation
-   Enterprise auditability
-   API-first integration

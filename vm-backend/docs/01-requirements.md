# Consolidated Requirements

-   Hierarchical multi-tenant enterprise platform with hybrid isolation
    tiers.
-   Flexible asset graph; no single asset source of truth.
-   Hybrid correlation with confidence and administrator override.
-   Canonical vulnerability + finding/evidence model.
-   Customer-configurable hierarchical contextual risk engine.
-   Controlled remediation with approvals, maintenance windows, dry-run,
    canary, backup, rollback and verification.
-   Enterprise connector platform, schema mapping, webhooks, polling,
    files, queues, replay, DLQ and lineage.
-   Event-driven distributed processing with idempotency, priority,
    backpressure and autoscaling.
-   Unified exposure query/search and relationship-aware queries.
-   Enterprise authentication and RBAC + ABAC + resource policy.
-   Full cloud security, SBOM/software intelligence and non-CVE security
    findings.
-   Policy-driven finding lifecycle, SLA/escalation and risk exceptions.
-   Policy-driven notifications.
-   Enterprise dashboards/reports.
-   Immutable/forensic audit.
-   Long-term temporal data and point-in-time reconstruction.
-   Versioned REST APIs with bulk/async/webhook capabilities.
-   Read-only AI assistant with enterprise guardrails.
-   Enterprise workflow engine.
-   Enterprise controlled remediation.
-   MongoDB + Redis + object storage + dedicated search + queue/event
    infrastructure.
-   Multi-AZ DR, enterprise observability and high-scale horizontal
    processing.
-   SaaS, dedicated/private VPC and customer AWS account deployment.
-   Enterprise security and SOC 2/ISO 27001-oriented controls.
-   Full platform scope is the target; implementation remains
    dependency-ordered.

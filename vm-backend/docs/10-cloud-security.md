# Cloud Security Exposure

Support AWS, Azure and GCP through normalized cloud-resource models.

Capabilities: continuous discovery, CSPM, workload context, CIEM,
network exposure, vulnerability correlation, misconfiguration detection,
sensitivity, attack paths, drift, historical change and remediation.

Cloud accounts/subscriptions/projects are hierarchy nodes. Prefer
short-lived/delegated credentials. Cloud evidence retains source account
and observation timestamps.

# SBOM & Software Intelligence

Support SPDX and CycloneDX. Normalize PURL, CPE, package-manager IDs,
vendor/product IDs, version ranges and hashes.

Capabilities: direct/transitive dependencies, SBOM history/diff, runtime
reconciliation, build-to-runtime lineage, reachability, provenance,
malicious package signals, dependency confusion signals, EOL, license
policy, vulnerability correlation and upgrade planning.

An SBOM is evidence/inventory; runtime exposure and reachability are
separate signals.

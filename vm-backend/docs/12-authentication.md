# Authentication

Support username/password, JWT/session, MFA, SAML SSO, OIDC, OAuth 2.0,
enterprise IdPs, service accounts and API keys.

Requirements: secure password hashing, session expiry/revocation, token
rotation, refresh-token controls, MFA recovery, brute-force protection,
authentication telemetry, secure cookies where applicable and managed
secret storage.

Authentication establishes identity; authorization independently
determines access.

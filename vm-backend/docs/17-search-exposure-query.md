# Unified Exposure Query Engine

Search assets, findings, vulnerabilities, software, cloud resources,
identities, controls, owners and relationships.

Modes: keyword, structured filter, relationship, graph traversal,
attack-path, risk, historical, saved searches and dashboard queries.

MongoDB/domain storage is authoritative; search indexes are derived.
Indexed documents contain tenant scope, canonical ID, source version and
index schema version. Search always applies authorization, not only
tenant filtering.

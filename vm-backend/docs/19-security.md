# Security & Compliance

Secure SDLC requires threat modeling, SAST, DAST, SCA, container/IaC
scanning, dependency/secret scanning, SBOM generation, signed artifacts
where practical and penetration testing.

Platform controls: TLS, encryption at rest, KMS, managed secrets, least
privilege, segmentation, WAF/DDoS controls, secure headers, validation,
rate limiting and comprehensive audit.

Architecture should support SOC 2 and ISO 27001-oriented controls.
Certification/compliance claims require formal assessment.

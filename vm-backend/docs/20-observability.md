# Observability

Use OpenTelemetry-compatible logs, metrics and traces.

Correlate service, environment, tenant, integration, job, event, request
and correlation ID.

Monitor API availability/latency, queue lag, ingestion throughput, job
success/failure, connector freshness, search latency, database/cache
health, notification delivery and remediation execution.

Avoid uncontrolled high-cardinality metric labels. Sensitive data must
not appear in logs.

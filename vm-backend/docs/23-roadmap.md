# Implementation Roadmap

## 1. Foundation

Repository, config, identity, tenant context, authorization, persistence
abstractions, API standards, audit, observability, events, CI/CD and
security gates.

## 2. Core exposure

Assets, correlation, vulnerabilities, evidence, findings, ownership,
lifecycle, SLA and risk.

## 3. Intelligence/integration

Connector SDK, universal ingestion, NVD/OSV/MITRE and other feeds,
normalization, reconciliation, replay and indexing.

## 4. Graph/software

Exposure graph, attack paths, SBOM, package intelligence, runtime
reconciliation and history.

## 5. Enterprise operations

Workflows, exceptions, notifications, reports and remediation.

## 6. Cloud/deployment

AWS/Azure/GCP, cloud exposure, drift, hybrid deployment and DR.

## 7. AI

Authorized retrieval, natural-language query/explanation, remediation
recommendations and AI audit/privacy controls.

## 8. Hardening

Load, security, failure-injection, DR and compatibility testing.

Foundational requirements---tenant isolation, authorization,
auditability, provenance, observability and idempotent async
processing---apply from the first production-capable release.
